📞 **PwC Task 1: Call Centre Trends Dashboard**
An interactive Power BI dashboard analyzing call center performance trends. Features include drill-down reports, KPIs, and visual insights on metrics like call volume, resolution rates, and customer satisfaction. Built for data-driven decisions to enhance operational efficiency.

📊 **Project Overview**
This project involves creating an interactive Power BI dashboard to analyze call center performance trends. The dashboard provides insights into key performance indicators (KPIs) such as call volume, resolution rates, and customer satisfaction.

📁 **Repository Contents**
1.Call Center Trends.pbix: Power BI dashboard file containing visualizations and reports.
2.Call-Center-Dataset.xlsx: Dataset used for analysis.

🛠️ **Tools & Technologies**
1.Microsoft Power BI
2.DAX (Data Analysis Expressions)
3.Power Query

📈 **Key Features**
1.Interactive Visualizations: Drill-down reports for in-depth analysis.
2.KPI Tracking: Monitor key metrics like call volume and resolution rates.
3.Customer Satisfaction Analysis: Visual insights into customer feedback.
4.Operational Efficiency: Identify areas for improvement in call center operations.

📊 **Dashboard Highlights**
1.Call Volume Trends: Analyze call patterns over time.
2.Resolution Rates: Track the percentage of resolved calls.
3.Customer Satisfaction: Assess customer feedback and satisfaction levels.
4.Agent Performance: Evaluate individual agent metrics.
